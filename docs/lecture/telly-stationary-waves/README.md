# Telly lecture: What Builds a Stationary Wave?

Slide deck on the Telly model (equations, inputs and outputs), the five `AC_SW_*`
stationary-wave experiments, and their results.

- Published deck (private; share from the page's Share menu): https://claude.ai/artifact/RrGvRvHPY361onwRt9VC81
- `project/deck.json` is the slide index; `project/slides/<id>.html` is one slide each.
  These are the exact files published to that deck, in the Slides format (1920x1080 slides,
  inline styles).
- `Telly_stationary_waves.pptx`: an editable PowerPoint version (native text, tables, a native chart and the
  figures as pictures; colors and fonts come from the theme). Rebuild it with `python3 build_pptx.py`
  (needs `pip install python-pptx`). It is built from the same content as the web deck but laid out
  separately, so check the layout when you open it. The deck page's Share > Export menu also gives
  PowerPoint or PDF copies.
- `viewer.html` (with the `images/` folder) shows the web deck in any browser; `python3 build_viewer.py` rebuilds it.
- The results slides are placeholders until the five-year `AC_SW_*` runs finish.
